What the roles mean

Documents: manager = everything + approve / reopen + delete. staff = create documents, edit drafts, record payments. viewer = view and download only.

Inventory: admin = everything + delete + stock count (adjust). storekeeper = products, suppliers, stock in / out. viewer = view only.

Employees: admin = everything + salary + kiosk PIN + settings. supervisor = attendance, overtime hours, tasks (salary is hidden). viewer = view only (no salary).
